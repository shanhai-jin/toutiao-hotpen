# 双形态写作指南

本指南覆盖两种形态：**微头条**（100-500 字互动体）与**头条长文**（800-1500 字观点体）。两者节奏、结构、收尾完全不同，先选形态再动笔。

## 第零步：形态选择

| 维度 | 微头条 | 头条长文 |
|---|---|---|
| 字数 | 100-500（建议 200-300） | 800-1500（目标 900-1300，多篇刻意错开） |
| 结构 | 钩子→事实→细节→互动提问 | 导语→骨架正文→观点落点 |
| 导语 | 无 | 有，80-120 字，单独成行（│ 前缀） |
| 配图 | 1-3 张（1 张主图最佳） | 封面 1 + 插图 ≥2 |
| 适写 | 快评、日常、情绪共鸣 | 深度解读、观点输出、行业观察 |

形态信号：用户说"短/简/快/聊聊"→微头条；"长文/深度/观点/分析"→长文；信号模糊→主动确认。

## 第一步：选题与强制增量

1. 抓当日/近 3 天热点，交叉核实硬数据
2. **强制增量（热点改写必做）**：先列 3 个常见角度（如政策罗列、情绪共鸣、追星吃瓜），再强制产出 ≥2 个增量角度：
   - 独家观点：别人没说的因果链
   - 支撑数据：能落数字的佐证
   - 类比案例：把陌生话题挂到读者已知经验上
   - 反向立场：有依据地唱反调
   - 利益相关方视角：谁赚谁亏、落到谁头上
3. 纯搬运（只复述事件）不出稿

## 第二步：标题

15-30 字资讯感事实句，关键词前置。三原则：

1. **事实感**：标题里要有具体的人/事/数字，不空喊
2. **数字前置**：核心数字尽量放前半句
3. **禁极限词/悬念词/强迫词**：「惊！」「速看」「不看后悔」类是严重标题党，直接扣分

## 第三步：正文硬规范（两形态通用）

- 数字一律阿拉伯数字（"3 件事"不是"三件事"）；汉字数词+量词是高风险特征
- 零破折号、零英文残留（外文名用通行中文译名）
- 每段 ≤4 句且 ≤155 字；段首不断裂（禁止"短句。长句"式开头）
- **信息增量硬要求**：每篇必须给到 1 个读者原本不知道的东西，可以是数据、内情，或一个明确的出处
- 涉健康、功效、收入的表述必须挂"宣称/据报道"归属，不得写成既定事实

## 第四步：长文骨架（三选一轮换，禁连续两篇同骨架）

- **骨架 A · 叙事先行**：亲友/场景小故事切入 → 引出新闻 → 拆解 → 落点
- **骨架 B · 数据先行**：核心数字开场 → 数据对比 → 解释为什么 → 落到普通人
- **骨架 C · 对话体**："你敢信吗"式直接对话 → 层层设问推进 → 开放式收尾

人设与开场句式同步轮换（如：家人→同学→同事），同批多篇不得重样。

## 第五步：收尾

- 微头条：开放式提问（"你们那儿呢？"），不诱导"评论区扣 1"、不私信导流
- 长文：观点落点 + 金句，可留互动问句但不凑数

## 去AI味（交付前自查，详见 deai-flavor.md）

删除套路填充词；句长长短交错；删冗余金句；细节具体化。**去痕不等于去情绪**，有立场的强判断必须保留。
